# Поэтапная миграция на Mini App с общей моделью данных

Listik-bot будет мигрировать на Mini App поэтапно: новый web-интерфейс и существующий Telegram UI некоторое время работают параллельно с одной SQLite-базой и одной бизнес-логикой. Обязательные сценарии списка, комнат, категорий и шаблонов сохраняются в Mini App, а админские команды и еженедельные напоминания пока остаются в боте; это предотвращает расхождение данных и оставляет работающий fallback на время стабилизации нового интерфейса.

## Considered Options

- Полностью заменить Telegram UI одним релизом: быстрее визуальный переход, но нет безопасного отката и выше риск потери сценариев.
- Создать отдельную базу для Mini App: изолирует разработку, но создаёт две конкурирующие версии списка и требует синхронизации.
- Запустить Mini App параллельно с существующим ботом на общей базе: выбранный вариант сохраняет данные и позволяет проверять новый UI постепенно.
