# Атомарное применение шаблона

Применение шаблона в Mini App проходит через preview и подтверждение пользователя. Выбранные для каждой конфликтующей позиции действия (`объединить`, `заменить`, `оставить`) выполняются одной транзакцией: при ошибке или конфликте версии не сохраняется частичный результат. Это предотвращает состояние, в котором часть шаблона уже добавлена, а остальные позиции потеряны.

## Consequences

- API должен принимать весь набор решений одним запросом;
- frontend показывает итог до записи и повторно загружает список после успешного применения;
- при конфликте версии пользователь получает актуальные данные и может заново подтвердить операцию;
- массовые действия могут быть shortcuts поверх per-item решений, но не отдельным несовместимым механизмом.
