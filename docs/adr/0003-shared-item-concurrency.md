# Правила совместного изменения товара

Для общего списка добавление товара с тем же названием и совместимой группой единиц выполняется как атомарное объединение количества. Ручное редактирование товара выполняется относительно версии, которую видел пользователь: если другой участник уже изменил товар, сервер отклоняет устаревшую запись и возвращает актуальное состояние вместо молчаливого last-write-wins.

## Consequences

- у товара появится версия или эквивалентный маркер изменения;
- API и realtime-события должны возвращать актуальное состояние товара;
- UI показывает пользователю конфликт ручного редактирования и предлагает повторить изменение на новой версии;
- применение шаблона получает per-item действия `объединить`, `заменить`, `оставить` и `отменить`;
- атомарное объединение требует короткой транзакции и согласованного сравнения имени и группы единиц.
