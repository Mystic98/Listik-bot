# Telegram Bot для списка покупок

Совместный список покупок с шаблонами, категориями и автоматической сортировкой по отделам супермаркета.

## Возможности

- Совместный список покупок для семьи/компании
- Автоматическая категоризация продуктов (молочные, мясо, овощи и т.д.)
- Шаблоны для быстрого наполнения списка
- Объединение дубликатов с конвертацией единиц (кг+г, л+мл)
- Управление доступом: новые пользователи проходят одобрение админа
- Еженедельное напоминание в субботу в 19:00


## Локальный запуск

```bash
# Установить uv (если нет)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Установить зависимости
uv sync --all-extras

# Создать .env из примера
cp .env.example .env
# Заполнить BOT_TOKEN и ADMIN_ID

# Запустить
uv run python bot.py
```

Для разработки интерфейса Mini App:

```bash
cd frontend
npm ci
npm run dev
```

## Запуск через Docker

### Требования

- Docker и Docker Compose
- VPS: 1 ядро CPU, 512 МБ RAM, 1 ГБ диск

### Быстрый старт

```bash
# Клонировать репозиторий
git clone <repo-url> grocery_shopping && cd grocery_shopping

# Создать .env
cp .env.example .env
nano .env  # Заполнить BOT_TOKEN и ADMIN_ID

# Запустить
docker compose up -d
```

### Запуск с PostgreSQL и Mini App

```bash
cp .env.example .env
# Заполнить BOT_TOKEN, ADMIN_ID, POSTGRES_PASSWORD и MINI_APP_URL
docker compose -f docker-compose.yml -f docker-compose.postgres.yml up -d --build
```

При запуске контейнера миграции Alembic применяются автоматически. `MINI_APP_URL` должен быть доступен по HTTPS; доменное имя не обязательно, если используется HTTPS на публичном IP. Чтобы оставить внешний порт 443 свободным для VPN, Mini App работает по адресу `https://72.56.70.155:8443/`. На VPS задайте такой же `MINI_APP_URL` в `.env` и разрешите входящие TCP-подключения на порт 8443 в firewall. Бот применяет адрес кнопки меню при запуске.

### Полезные команды

```bash
docker compose logs -f          # Логи контейнера
docker compose restart          # Перезапуск
docker compose down             # Остановить
docker compose up -d --build    # Пересобрать и запустить
```

## Конфигурация

Создайте бота через [@BotFather](https://t.me/BotFather) и узнайте свой Telegram ID через [@userinfobot](https://t.me/userinfobot).

Переменные окружения (`.env`):

| Переменная | Обязательна | Описание | По умолчанию |
|-----------|-------------|----------|-------------|
| `BOT_TOKEN` | Да | Токен Telegram бота | — |
| `ADMIN_ID` | Да | Telegram ID администратора | — |
| `DATABASE_PATH` | Нет | Путь к SQLite-файлу в legacy-режиме | `/app/data/grocery.db` |
| `DATABASE_URL` | Нет | PostgreSQL URL; при заполнении становится источником данных | — |
| `WEBAPP_ENABLED` | Нет | Запустить FastAPI/WebSocket рядом с ботом | `false` |
| `MINI_APP_URL` | Нет | HTTPS-адрес Mini App для кнопки меню Telegram | — |
| `MINI_APP_HOST` | Нет | Адрес HTTP-сервера Mini App | `0.0.0.0` |
| `MINI_APP_PORT` | Нет | Порт HTTP-сервера Mini App | `8080` |
| `LOG_DIR` | Нет | Папка для логов | `logs` |

## Команды

### Для всех пользователей

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация / инструкция |
| `/help` | Справка |
| `/add <продукт>` | Добавить продукт |
| `/list` | Показать список |
| `/done <N>` | Отметить купленным |
| `/undo <N>` | Вернуть в список |
| `/remove <N>` | Удалить |
| `/clear` | Удалить все купленные |

### Для администратора

| Команда | Описание |
|---------|----------|
| `/pending` | Список ожидающих подтверждения |
| `/users` | Список пользователей с доступом |

## Система доступа

1. Новый пользователь пишет `/start` → попадает в список ожидающих
2. Пользователь видит сообщение об ожидании подтверждения
3. Админ использует `/pending` и нажимает **Одобрить** или **Отклонить**
4. Одобренный пользователь получает уведомление

## Формат добавления продуктов

**Интерактивный режим (через кнопку ➕ Добавить):**

1. Введите название продукта
2. Выберите единицу измерения (кг, г, шт, л, мл, уп) или "Без меры"
3. Введите количество

**Быстрый режим (через команду):**

```
/add молоко 2л
/add яйца 10 шт
/add сыр 500г
/add хлеб
```

**Объединение дубликатов** — одинаковый продукт с той же группой единиц суммируется:

```
/add молоко 2л  →  "молоко 2л"
/add молоко 3л  →  "молоко 5л" (обновлено)
/add молоко 1шт →  "молоко 1шт" (новый продукт, другая мера)
```

## Категории

Продукты автоматически распределяются по отделам супермаркета:

Молочные продукты, Мясо, Рыба, Овощи, Фрукты, Хлеб, Бакалея, Замороженные, Консервы, Напитки, Сладости, Бытовое, Другое

Распознавание по словарю ключевых слов + нечёткий поиск. Пользователь может вручную сменить категорию — выбор сохраняется и переиспользуется.

## CI/CD

Workflow находится в `.github/workflows/ci-cd.yml`.

CI запускается для push и pull request в `main` и `feature/mini-app-migration`:

- устанавливает Python-зависимости через `uv`;
- запускает backend-тесты с проверкой покрытия не ниже 60%;
- проверяет типы и собирает frontend;
- проверяет сборку Docker-образа.

CD запускается после успешного CI при push в текущую рабочую ветку `feature/mini-app-migration`:

- подключается к VPS по SSH;
- выполняет fast-forward обновление репозитория;
- пересобирает и перезапускает PostgreSQL, бота и Caddy;
- проверяет `https://<VPS_HOST>:8443/healthz`.

Если VPS Secrets ещё не добавлены, CI завершится, а шаг деплоя будет пропущен.

Для CD в настройках GitHub-репозитория нужно добавить secrets:

| Secret | Значение |
|--------|----------|
| `VPS_HOST` | `72.56.70.155` |
| `VPS_USER` | `root` |
| `VPS_SSH_KEY` | Приватный SSH-ключ для подключения к VPS |
| `VPS_KNOWN_HOSTS` | Результат `ssh-keyscan -H 72.56.70.155` |
| `VPS_PATH` | `/root/Listik-bot` |

После переноса продакшена на `main` ветку деплоя нужно будет заменить в workflow на `main`.

Ручной деплой на VPS:

```bash
cd /root/Listik-bot
git pull --ff-only origin feature/mini-app-migration
# В .env установить MINI_APP_URL=https://72.56.70.155:8443/
docker compose -f docker-compose.yml -f docker-compose.postgres.yml up -d --build
```
